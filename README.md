# Agentic Product Development

Research and evolving ways of working for building real products with AI agents.

This repository is a practical research notebook based on actual product-development experience. The goal is to learn how effective builders divide work between humans, general-purpose AI assistants, coding agents, GitHub, and deployment/tooling systems — and to turn useful findings into simpler, more effective ways of working.

This is not intended to become a generic collection of AI coding tips or a heavyweight process framework. Research should precede new process. Practices should earn their place through evidence and real use.

## Current focus

The first investigation asks:

> How are effective solo builders using ChatGPT/Claude-style thinking agents together with Codex/Claude Code-style coding agents and GitHub to build real products — and where do they draw the boundaries between product thinking, planning, implementation, review, and release?

See [Research Questions](research-questions.md) for the current prioritized backlog.

## Evidence

Useful evidence can come from:

- actual product-building experiments and case studies;
- official documentation when the question is tool-specific;
- practitioner discussions on Reddit, GitHub, developer communities, Discord, and similar forums;
- credible practitioner write-ups describing workflows they actually use;
- comparisons and experiments performed against real projects.

The aim is to distinguish observed practice from assumptions, vendor guidance, and workflow ideas that merely sound plausible.
